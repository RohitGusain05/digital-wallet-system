# Digital Wallet System

A full-stack digital wallet portfolio project built with React, Node.js, Express, PostgreSQL and MongoDB.

## Features

- JWT-based registration and login
- Wallet balance management
- Deposit and withdrawal flows
- Wallet-to-wallet transfers by recipient email
- Recent transaction history
- Idempotency keys for wallet write operations
- Request rate limiting and security headers
- PostgreSQL + MongoDB persistence
- React/Vite responsive frontend
- GitHub Actions CI for backend and frontend builds

## Project structure

```text
backend/     Node.js + Express REST API
frontend/    React + Vite web application
.github/     GitHub Actions CI workflows
```

## Local development

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run migrate
npm start
```

The API runs on `http://localhost:5000` by default.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend uses `VITE_API_URL` when provided and otherwise targets `http://localhost:5000/api`.

Example frontend environment variable:

```text
VITE_API_URL=http://localhost:5000/api
```

## Deployment configuration

For a hosted deployment, keep secrets out of Git. Configure environment variables in the hosting provider instead.

### Backend environment variables

- `PORT` — supplied by the hosting platform when required
- `DATABASE_URL` — PostgreSQL connection string
- `MONGODB_URI` — MongoDB connection string
- `JWT_SECRET` — long random signing secret
- `JWT_EXPIRES_IN` — JWT lifetime, for example `1d`
- `CORS_ORIGIN` — frontend origin, for example `https://your-app.vercel.app`
- `NODE_ENV=production`

### Frontend environment variable

- `VITE_API_URL` — deployed backend API base URL, including `/api`

## CI

GitHub Actions builds the backend and frontend on relevant changes. Keep the dependency versions pinned and commit each package lockfile generated by the package manager before switching CI from `npm install` to `npm ci`.

## Important note

This is a portfolio/demo application, not a real banking or payment product. Do not use real financial credentials, production payment data, or real money with a deployment of this project.
